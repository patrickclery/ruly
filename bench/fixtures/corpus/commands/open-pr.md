# Open a Pull Request

1. Confirm the branch is rebased on the latest main branch and the build passes locally.
2. Review the full diff and remove debugging output and unrelated changes.
3. Write the title in the commit subject format.
4. Write the description: what changed, why, how it was tested, and the riskiest part for the reviewer to focus on.
5. Link the issue and request a reviewer who knows the affected code.
6. Move the issue to in review.
