# Triage New Bugs

1. List issues of type bug created since the last triage that have no severity.
2. For each one, check that it has steps to reproduce, the environment and the observed error. Ask the reporter for anything missing.
3. Try to reproduce it. Record the result in a comment.
4. Set the severity: critical for data loss or an outage, high for a broken core flow, medium for a workaround-able problem, low for cosmetic issues.
5. Assign an owner and add the issue to the current cycle if it is critical or high.
6. Close duplicates with a link to the original.
