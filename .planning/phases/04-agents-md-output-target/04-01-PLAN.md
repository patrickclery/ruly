<objective>
Add the `agents` output target: `ruly squash RECIPE -a agents` writes the recipe's squashed body to `AGENTS.md` so any AGENTS.md-aware agent can consume a ruly recipe without a per-agent adapter, while recipe composition (`files`, `requires:`, overrides) stays ruly's layer.

Decision IDs index the bullets of `04-CONTEXT.md` `<decisions>` in document order: D-01 agent value `agents` with aliases `agents-md`/`agentsmd` in `normalize_agent`; D-02 default output `AGENTS.md`, `-o` overrides; D-03 no new command or recipe key, reuse `--agent`; D-04 body is the same squashed markdown as the Claude output; D-05 skills inlined under `## Skills`, commands and subagents not emitted, one-line notice of what was skipped; D-06 hooks, MCP servers, settings not emitted (notice only); D-07 generated-file header comment; D-08 cursor unchanged (README note in plan 04-02, removal deferred); D-09 `clean -a agents` removes AGENTS.md and `--git-ignore`/`--git-exclude` include it; D-10 post-squash checks run on the AGENTS.md output; D-11 (Claude's discretion) notice wording and skills as plain sections.

Discretion choices made here (D-11 and gaps the decisions leave open):
- Skills render as plain sections: a skill's leading YAML frontmatter is dropped (Claude Code directives such as `description:` mean nothing inside AGENTS.md), its headings are demoted two levels (h1 to h3, capped at h6, fenced code untouched), and a `### <skill-name>` heading is prepended when the body does not start with a heading.
- Notice: one stdout line, `ℹ️  AGENTS.md target skips Claude-only parts: <list>`, list order commands (N), subagents (N), hooks, mcp_servers, model, isolate; key names and counts only, never values.
- `clean -a agents` targets only the agents output, marker-gated. It does not remove `.claude/` or `.mcp.*`, because the agents target never writes them and users commonly keep Claude output beside AGENTS.md. `--deepclean` keeps its current meaning (Claude artifacts).
- `squash -a agents` refuses to overwrite an existing file that lacks the marker (security mitigation T-04-01; AGENTS.md is often hand-written and committed).
- Recipe scripts are still copied to `.claude/scripts/`: the squashed body's script references are rewritten to those paths, and scripts are not on the D-05/D-06 skip list.
- `-o CLAUDE.local.md` with `-a agents` resolves to `AGENTS.md`, the same "equals the default means not explicit" rule `SquashHelpers.determine_output_file` already applies.

Purpose: cross-agent reach through the AGENTS.md standard (research "Strategic options" #1) without fan-out adapters.
Output: new `Services::AgentsMd`, CLI routing for squash/clean, display line, fixture, unit and CLI specs.
</objective>
